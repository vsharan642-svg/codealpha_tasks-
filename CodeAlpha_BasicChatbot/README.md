# 🤖 Python Chatbot

### CodeAlpha Python Programming Internship | Task 3

A simple, interactive rule-based chatbot developed using Python that responds to user messages, answers basic questions, and provides a friendly conversational experience through the command line.

---

## 🚀 Project Overview

The Python Chatbot is a command-line conversational application designed to demonstrate fundamental Python programming concepts.

It interacts with users through predefined responses and supports basic conversations, personal name recognition, date and time information, and helpful command suggestions.

## ✨ Features

- 👋 Interactive greetings and responses
- 🧑 User name recognition
- 💬 Basic conversational responses
- 🕒 Current time information
- 📅 Current date information
- ❓ Help command for available features
- 🔄 Continuous conversation loop
- 🚪 Exit command to end the session
- 🛡️ Handles unknown messages gracefully

## 🛠️ Technologies Used

- **Python 3**
- Conditional Statements (`if`, `elif`, `else`)
- Loops (`while`)
- String Handling
- User Input Handling
- `datetime` Module

## ▶️ How to Run

### Prerequisites

- Python 3 installed
- VS Code or any Python-compatible editor

### Execution Steps

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Execute the following command:

```bash
python chatbot.py
```

5. Start chatting with the chatbot.
6. Type `help` to explore available commands.
7. Type `bye` to end the conversation.
