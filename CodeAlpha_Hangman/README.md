Hangman Game in Python

📌 About the Project

This is a simple command-line Hangman game developed using Python. The player needs to guess the secret word one letter at a time. The player has a maximum of 6 wrong guesses to find the correct word.

✨ Features

•	Random word selection

•	User name input

•	Letter-by-letter guessing

•	Maximum of 6 wrong guesses

•	Input validation

•	Prevents repeated guesses

•	Win and lose messages

🛠️ Technologies Used

•	Python

•	Random module

•	VS Code

🚀 How to Run the Project

	Install Python on your computer.

	Open the project folder in VS Code.

	Open the terminal.

	Run the following command:

	python hangman.py

	Enter your name and start guessing letters.

🎯 How to Play

	The game randomly selects a secret word.

	The word is displayed as underscores.

	Enter one letter at a time.

	Correct guesses reveal letters in the word.

	You can make up to 6 wrong guesses.

	Guess the complete word to win!
